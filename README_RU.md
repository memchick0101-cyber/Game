# Life in the Six-Faced World — PWA

Автономный мобильный прототип фанатского симулятора жизни по мотивам Mushoku Tensei.

## Файлы
- `index.html` — интерфейс, вертикальная мобильная вёрстка.
- `game.js` — игровая логика, NPC, действия, характеристики, отношения, события, локальное сохранение и экспорт/импорт.
- `manifest.webmanifest` — настройки установки как PWA.
- `sw.js` — кэширование файлов для офлайн-запуска.
- `icon.svg` — значок приложения.

## Важно про iPhone
Для установки PWA нужен HTTPS-сайт. Само открытие `index.html` как локального файла не устанавливает офлайн-приложение. Самый простой бесплатный способ — GitHub Pages.

## Публикация через GitHub Pages
1. Создай репозиторий на GitHub.
2. Загрузи в корень репозитория все файлы из этой папки.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main` и папку `/ (root)`, затем Save.
6. Дождись появления адреса вида `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
7. Открой этот адрес в Safari на iPhone и дождись полной загрузки.
8. Нажми «Поделиться» → «На экран Домой» → включи «Открывать как веб-приложение», если переключатель доступен → «Добавить».
9. Запусти приложение с домашнего экрана хотя бы один раз при подключённом интернете. После этого оболочка игры должна открываться офлайн.

## Сохранения
- Автосохранение использует `localStorage` в браузере.
- Вкладка «Сохранения» позволяет экспортировать JSON-файл и импортировать его обратно.
- Не очищай данные Safari для сайта, иначе локальное сохранение может быть удалено.
- Рекомендуется периодически экспортировать резервную копию.

## Обновление
При изменении файлов увеличивай версию CACHE в `sw.js` (например, `six-faced-life-v2`), чтобы Service Worker обновил кэш.

## Ограничения текущей версии
Это рабочий игровой прототип, а не законченная RPG. NPC генерируются процедурно, но пока не имеют сложных индивидуальных сюжетных линий; карта, сюжетные арки, боевые сцены, полноценная магическая система и наследование поколений требуют дальнейшей разработки. Названия и элементы вселенной используются в фанатском неофициальном проекте.
